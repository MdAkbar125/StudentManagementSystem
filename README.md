# Student Management System

A console-based Student Management System developed using Java.

## Features

- Add student
- View students
- Search student
- Update student
- Delete student
- Sort students by marks
- Calculate grades

## Technologies

- Java
- OOP
- ArrayList
- Collections
- CRUD Operations

## Concepts Used

- Classes and Objects
- Encapsulation
- Constructors
- Getters and Setters
- ArrayList
- Searching and Sorting
- Conditional Statements and Loops

javac *.java
